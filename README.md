# 🚗 საქართველოს ავტოგზების რუკა

ინტერაქტიული ვებ-რუკა საქართველოს საავტომობილო გზების ქსელისა — საერთაშორისო (**S**) და შიდასახელმწიფოებრივი (**Sh**) მარშრუტები, რეგიონები და ქვეყნის ადმინისტრაციული საზღვარი.

🌐 **ვებ-გვერდი:** [car.qgis.ge](https://car.qgis.ge/)

დამატებით, გვერდზე ინტეგრირებულია **[საგზაო ჯარიმების ცნობარი](https://car.qgis.ge/jarimebi.html)** — ჯარიმების შემოწმების/გადახდის ოფიციალური პორტალები და ადმინისტრაციულ სამართალდარღვევათა კოდექსის მუხლების საძიებო სია (წყარო: [sask.source.md](sask.source.md)).

---

## 🗺️ რუკის შრეები

| შრე | აღწერა |
| :--- | :--- |
| ❄️ **ზამთრის გზები** | საქართველოს გზები — საერთაშორისო (S) და შიდასახელმწიფოებრივი (Sh) მარშრუტები |
| 🗺️ **რეგიონები** | ადმინისტრაციულ-ტერიტორიული ერთეულები (ოკუპირებული ტერიტორიები გამოყოფილია) |
| 🇬🇪 **საზღვარი** | ქვეყნის ადმინისტრაციული საზღვარი |
| ⛽ **საწვავი** | ავტოგასამართი სადგურები (ბენზინი / ბუნებრივი / თხევადი გაზი) |
| 🧼 **სამრეცხაო** | ავტოსამრეცხაოები |
| 🔧 **ავტოსახელოსნო** | ავტოსერვისები / ხელოსნები |
| 🔩 **ავტონაწილები** | ავტონაწილების მაღაზიები |
| 🛣️ **მარშრუტები** | რეკომენდებული მარშრუტები |

**საბაზისო რუკები:** CARTO (ღია / მუქი) და Esri World Imagery (სატელიტი) — გასაღების გარეშე.

## ✨ ფუნქციები

- ობიექტზე დაჭერით — ინფორმაცია (მარშრუტის სახელი, რეგიონი და სხვ.)
- მდებარეობის განსაზღვრა, მასშტაბირება, მანძილის გაზომვა
- შრეების ჩართვა/გამორთვა და ლეგენდა
- მობილურზე მორგებული ინტერფეისი

## 🛠️ ტექნოლოგია

- [Leaflet](https://leafletjs.com) — ინტერაქტიული რუკა
- [QGIS](https://qgis.org) + [qgis2web](https://github.com/tomchadwin/qgis2web) — მონაცემების მომზადება და ვების ექსპორტი

## 📁 სტრუქტურა

```
├── index.html          # ვებ-გვერდი (რუკა)
├── jarimebi.html       # საგზაო ჯარიმების ცნობარი (საძიებო)
├── jarimebi.data.js    # ჯარიმების მონაცემები (sask.source.md-დან გენერირებული)
├── sask.source.md      # საგზაო დარღვევების წყარო (ადმ. სამართალდარღვევათა კოდექსი)
├── css/ js/ data/       # რუკის რესურსები და GeoJSON მონაცემები
├── legend/ images/      # ლეგენდა და აიქონები
├── webfonts/            # შრიფტები
├── Project/wrm.qgz      # QGIS პროექტის ფაილი (წყარო)
├── Geodatabase/         # GeoPackage მონაცემთა ბაზა (წყარო)
├── KML/                 # KMZ ექსპორტი
└── WEB/                 # qgis2web-ის საწყისი ექსპორტი (არქივი)
```
